# 📚 Plataforma de Registro de Obras Literárias Lidas

## 📌 Sobre o projeto

A **Plataforma de Registro de Obras Literárias Lidas** é uma aplicação desenvolvida
para auxiliar leitores no acompanhamento e organização de suas leituras.

A plataforma permite registrar livros lidos, acompanhar o progresso de leitura,
definir metas e receber recomendações de obras de acordo com as preferências do
usuário.

## 🎯 Público-alvo

Leitores que desejam organizar suas leituras, acompanhar seu progresso e descobrir
novas obras literárias.

## ✨ Funcionalidades

- 👤 Cadastro de usuários e preferências;
- 📚 Registro de livros lidos;
- 📊 Dashboard com recomendações;
- 🎯 Definição e acompanhamento de metas de leitura;
- 📈 Acompanhamento do histórico e progresso das leituras.

## 🚀 Objetivo

O projeto tem como objetivo oferecer uma ferramenta simples e intuitiva para
organizar a vida literária dos usuários, permitindo acompanhar seus hábitos de
leitura e facilitar a descoberta de novos livros.
